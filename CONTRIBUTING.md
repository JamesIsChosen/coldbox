# Contributing to Coldbox

All work is governed by the compiled Markdown Machine state under
[`.markdown-machine/`](.markdown-machine/). Begin with
[`HANDOFF.md`](.markdown-machine/HANDOFF.md) and proceed only from a current
admitted Task.

Technical documents, the former roadmap, ADRs, packets, and historical review
process remain useful evidence, but they are not current authority unless an
admitted Markdown Machine record binds their exact bytes as context.

The complete pre-adoption Markdown governance surface is retained byte-for-byte
under [`.markdown-machine/history/`](.markdown-machine/history/) as non-current
provenance.
