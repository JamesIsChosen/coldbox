Entropy Lab / P1.1 + P1.2

Collect physical/manual entropy from dice, coin flips, shuffled cards, or genuinely user-supplied hex, then combine it with fresh CSPRNG bytes. A sound device RNG supplies the selected normal output strength; the independently collected physical/manual contribution determines how much fallback protection remains if that RNG is completely compromised. The Generate controls are simulation conveniences powered by the same device RNG as CSPRNG; generated values are labeled and receive zero independent-source credit. Recording no physical/manual entropy is supported, but that is CSPRNG-only security rather than two-source protection.
