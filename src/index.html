▼ How the boundary is built ▼

01

A toolkit, not a wallet

Coldbox holds no coins, reaches no blockchain to move them, and signs nothing. It is a companion to your hardware wallets: it checks their work, manages your backups, and keeps the records.

02

Portable by default

One file on a USB stick, opened by double-clicking. The interface is designed for a narrow phone screen up through a desktop window, with no server and no install step.

03

Secrets get their own boundary

The sealed cold realm is active, and the airgap guard keeps its policy visible. The shell does not create a shortcut around that boundary.
