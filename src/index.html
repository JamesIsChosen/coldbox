▼ How the boundary is built ▼

01

A toolkit, not a wallet

Coldbox holds no coins, reaches no blockchain to move them, and signs nothing. It is a companion to your hardware wallets: it checks their work, manages your backups, and keeps the records.

02

Portable by default

One file on a USB stick, opened by double-clicking. The interface is designed for a narrow phone screen up through a desktop window, with no server and no install step.

03

Secrets get their own boundary

The sealed cold realm is active, and the airgap guard keeps its policy visible. The shell does not create a shortcut around that boundary.

Verify this file

Self-verification is circular, and this says so on purpose. The drop zone below hashes the bytes you give it and compares the result against a value compiled into this same running copy. A modified build could embed a hash that matches its own modified bytes and report a clean match regardless of what was changed. This catches accidental corruption — a bad download, damaged media — not deliberate tampering. For a check an attacker cannot forge, compare against the published .sha256 file with shasum / certutil / Get-FileHash, check the detached GPG signature, and ideally reproduce the build yourself from source. Full instructions: docs/02-security/verification.md in the source repository.
