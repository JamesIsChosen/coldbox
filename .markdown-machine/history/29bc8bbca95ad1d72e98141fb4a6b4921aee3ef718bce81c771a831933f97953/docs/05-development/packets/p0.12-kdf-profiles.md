## 6. Security impact

- No new warm-to-cold message type or secret-bearing field.
- No network permission is added or weakened.
- Benchmark eligibility is stricter than before: full vault health plus healthy Argon2id is required.
- Runtime airgap violation, CSP-canary failure, missing randomness, failed network neutering, crypto failure, or lockdown/refusal state prevents use.
- Benchmark inputs are a fixed non-secret passphrase and salt only; they follow the same Argon2 call shape as vault derivation and are wiped with the output hash.
- Benchmark calls remain serialized and overlapping UI/API requests are coalesced.
