# MM-RECOVERY/1

This registry defines deny-only recovery, evidence, revision, and continuity
records. It is read when records in these families are compiled or recovered,
not as a healthy bootstrap prerequisite. Recovery state never creates positive
authority. All revision chains, family reducers, edge guards, typed references,
and capacity calculations are finite and fail closed.

`HANDOFF_PROJECTION.basis_repository_commit` passes repository-basis freshness
when it equals local HEAD, or when the tree diff from that basis commit to local
HEAD contains no path under `.markdown-machine/` except
`.markdown-machine/HANDOFF.md`; paths outside `.markdown-machine/` may differ.
This is the sole self-projection exception. Any other governed-path delta fails
and requires regeneration. The exception never makes HANDOFF authoritative and
cannot mask a change to authority, intent, lifecycle, Tasks/Attempts, reviews,
STOP state, convergence, effects/resources, repository binding, Origin,
KernelManifest, or other governed state.

`ATTEMPT_RECORD` execution eligibility requires the exact current,
non-tombstoned Task and current operation preflight. Required enforcement
dimensions need current non-stale assessments at or above the configured
assurance. `SERIAL_PORTABLE/v1` with a `SERIAL` resource floor does not require
a fabricated reservation or fencing assessment; project-specific and stronger
floors retain their real reservation/proof requirements.
