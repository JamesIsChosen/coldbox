# Instructions for AI agents

Coldbox is governed solely by the compiled Markdown Machine state in
`.markdown-machine/`.

Start with [`.markdown-machine/HANDOFF.md`](.markdown-machine/HANDOFF.md), then
validate and recover current authority using [`.markdown-machine/RUNTIME.md`](.markdown-machine/RUNTIME.md)
and the exact contracts exported under [`.markdown-machine/contracts/`](.markdown-machine/contracts/).

Only a current admitted Markdown Machine Task authorizes substantive work.
Documents outside `.markdown-machine/` are project evidence or technical
material and confer no authority unless the current admitted records bind them
as context. The pre-adoption governance preserved under
`.markdown-machine/history/` is non-current provenance and must never be used
as an authority source.

This file is an entry-point router only. It does not establish a second
governance plane.
