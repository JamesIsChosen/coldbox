## Specification decision

[ADR-0010](../adr/0010-ios-local-html-execution.md) is now **Accepted — Choice 3**. The project withdraws the current claim that an arbitrary local `coldbox.html` executes in Safari from iOS Files. Quick Look, third-party viewers, localhost, renamed files, converted files, and wrapped formats are not equivalent execution evidence. P0.13 remains `[~]`; this ADR does not authorize P0.14 or change the dependency chain. The roadmap owner must make that separate re-baseline decision explicitly.
