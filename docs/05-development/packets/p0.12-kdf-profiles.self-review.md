## Security checklist

- The benchmark API and UI are embedded only in the cold document. The warm source/template have no benchmark identifier, control, or crypto global.
- Benchmark inputs are fixed and non-secret; no user passphrase, vault bytes, DEK, or seed crosses the realm boundary. Inputs and Argon2 output buffers are cleared after each run.
- Fast, Standard, and Paranoid use the exact profile parameters already authenticated by the vault header. The round-trip test rejects any silent fallback by checking the header fields.
- Profile runs are sequential, and likely-iOS detection prevents the known 256 MiB Paranoid allocation before it starts. Other failures become an unavailable result, never an implicit successful Argon2 timing.
- The browser harness retains the opaque-frame, CSP, network-blocking, protocol, tamper, timeout, lockdown, and missing-randomness checks.
- The complete diff was read, `git diff --check` passed, and the reserved `.review.md` path remains absent for independent review.
