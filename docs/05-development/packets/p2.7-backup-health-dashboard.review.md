### F2 - A future cold-verification timestamp is classified as `current`

**Severity:** blocking
**Location:** `src/backup-health.js` - `evaluate()`

The evaluator calculated `dueAt = verifiedAt + interval * DAY_MS` and classified
`current` whenever `now < dueAt`, without rejecting `verifiedAt > now`.

**Required action:** Detect `lastVerifiedAt > now` before current/overdue
calculation and fail closed to `invalid`/needs-review, or introduce an
explicitly designed clock-skew state. Add future-time and exact-boundary tests.

### F3 - Protocol-valid timestamp data can throw the evaluator

**Severity:** blocking
**Location:** `src/backup-health.js` - `isoDate()` / `evaluate()`

The canonical maximum JavaScript Date,
`+275760-09-13T00:00:00.000Z`, passed protocol validation, but adding a
one-day interval produced a finite number outside the representable Date range
and `toISOString()` threw `RangeError: Invalid time value`.

**Required action:** Check calculated due-date representability before
formatting or comparison. Overflow must return invalid/needs-review without an
exception, with a regression test.

### F4 - Required mobile `file://` testing is not complete

**Severity:** blocking
**Location:** `AGENTS.md` section 5 and the P2.7 packet device matrix

The packet recorded Playwright Chromium and Firefox on Windows but marked iOS
and Android untested. Responsive viewport emulation is not physical-mobile
evidence, and no explicit P2.7 waiver or deferment had been recorded.

**Required action:** Run P2.7 on a supported mobile browser through the local
file path, or make an explicit repository/user policy decision that defers or
alters this requirement before treating the deferral as non-blocking.

### F5 - Mandatory independent execution was unavailable

**Severity:** blocking
**Location:** `docs/05-development/review-protocol.md`

The required fresh checkout, command reruns, environment variation, deliberate
breakage, and independent build reproduction could not run because the review
environment could not clone GitHub. CI corroboration was not a substitute.

**Required action:** The next independent review must run in an environment
with checkout, dependency, and browser access and perform the complete review
protocol. No production-code change is required specifically for F5.
