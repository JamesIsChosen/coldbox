## 4. Findings

### F1 — Recorded upstream SHA-256 is not the SHA-256 of the pinned upstream bytes

**Severity:** blocking provenance
**Location:** `docs/05-development/dependencies.md` SLIP-39 row; ADR-0036; P2.1 packet; `src/cold/slip39.js` provenance header.
**Observed:** The branch records `21c15adf2a2f692662b469b609e6a3e42eb828d4fc5c13707f3a4beea027ea48` as the SHA-256 of upstream `src/slip39_helper.js`. A fresh download from exact commit `414a73b0a28f2fc966514b8f318eb6f68bf9979a` is 36,923 bytes and hashes to `2009d910cda84e81e3d75f78f6961a9b82258c66513f4160efc25c6a4f6a6c5e`. Its Git blob SHA-1 is the correctly recorded `8bcb9568c6c6191e686de2d34864088c644fc7b2`. The recorded `21c15...` value is the SHA-256 after LF→CRLF transformation, not the exact upstream bytes.
**Expected:** A value explicitly labeled as the SHA-256 of the upstream file must reproduce from the pinned upstream bytes without platform newline transformation.
**Required action:** Correct the SHA-256 assertions, define the exact-byte convention unambiguously, and add/re-run an independent exact-byte provenance check. Preserve the already-correct tag commit and Git blob identity unless new evidence requires otherwise.

### F2 — Build/lint gate fails open to executable `Math.random()` in the new cold security module

**Severity:** blocking security
**Location:** `scripts/lint.js` `scanSourceFile()`; exercised path `src/cold/slip39.js`.
**Observed:** In a disposable reviewer worktree I appended `void Math.random();` to `src/cold/slip39.js` and ran `npm run build`. The build exited **0** and emitted an artifact. The module was then restored byte-for-byte. `scripts/lint.js` defines an executable `Math.random` pattern but applies it only when `relative === 'src/capabilities.js'`; secret-handling `src/cold/**` files do not receive that rule.
**Expected:** The review protocol requires no `Math.random` anywhere in a security-relevant path and requires deliberate invalid mutations to fail with a non-zero exit.
**Required action:** Extend the security/forbidden-construct lint to reject executable `Math.random()` throughout the security-relevant cold source surface, add a regression test proving `npm run build` exits non-zero for this mutation, and rerun the independent negative gate.
